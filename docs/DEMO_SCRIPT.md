
# WalkLah Demo Script

## Starting state
1. Open WalkLah.
2. Select the agreed demo start and destination.
3. Show the baseline route and its distance/time.
4. Show the WalkLah route before the obstacle is verified.

## Submit a report
5. Open the report form.
6. Select the obstacle category.
7. Enter a short description and submit.
8. Confirm the report appears as pending.

## Verify and reroute
9. Open the operator dashboard.
10. Verify the report as an active obstacle.
11. Return to navigation and recalculate.
12. Show the changed route if an alternative exists.

## Clear the obstacle
13. Mark the report as cleared.
14. Recalculate the route.
15. Show that the previously blocked segment is available again,
    if it is still the shortest valid route.

## Wrap-up
16. Show dashboard metrics.
17. Explain how verified obstacle data can help township
    operators prioritise pedestrian infrastructure issues.

Note:
Use a pre-tested obstacle on a segment that the original
route actually traverses. Do not rely on a random report
to change the route during the presentation.
