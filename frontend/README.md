# WalkLah frontend

React + TypeScript + Vite + MapLibre GL JS client for the WalkLah prototype.

```powershell
cd frontend
npm install
Copy-Item .env.example .env.local
npm run dev        # http://localhost:5173
```

The backend must be running on `http://127.0.0.1:8000` (see `backend/HANDOFF.md`).
A full setup guide follows once the app is complete.
